# TGZA-Cipher-Caper

Dependancies 

Python, Cyptography, keyring, tkinter

INSTRUCTIONS:

1. Ensure python is installed if already installed, open cmd: python -v, run exit to return to cmd, if not installed navigate to https://www.python.org/downloads
2. Ensure pip is installed, comes native with python: pip --version, if does not return anything, or says not found, but you have python installed, try python -m pip --version, to run it as a python command, if again not found, refer to step 1
3. Verify tkinter is installed properly, it is a native library to python: python -m tkinter, a small window shows up, click exit
4. Install pythons cryptography library: pip install cryptography
5. Install keyring, if your running on windows, its simply: pip install keyring, if you are on linux, it is far more tedious, you then would need to download dependancies before keyring,
on linux, verify you have python, if not install it: sudo apt install python3-pip
on linux again then download dependancies: sudo apt install secretstorage dbus-python,
Then Finally the ease: Pip install keyring.
